
# AI Quant Trading System

An algorithmic trading research project combining
traditional quantitative strategies and machine learning.

## Project objectives

- Historical financial data collection and processing.
- Financial feature engineering.
- Quantitative trading strategies.
- Machine learning-based predictive models.
- Portfolio construction and risk management.
- Historical backtesting and paper trading simulation.

## Current progress

### Phase 1 - Data Exploration

- Historical market data retrieval using Yahoo Finance.
- OHLCV data exploration.
- Daily returns calculation.
- Cumulative returns.
- Simple Moving Averages (SMA).
- Momentum indicators.
- Historical volatility estimation.

## Technology stack

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn (planned)
- XGBoost (planned)
